# Yashirilgan (⚠) menyu bandlari

Sahifa toza ko‘rinsin deb keraksiz bandlar CSS orqali yashirildi (`.tdyu-ia-hide`).
HTML o‘chirilmagan — keyin kerak bo‘lsa qayta ko‘rsatish mumkin.

Batafsil ro‘yxat: `hidden-ia-items.json`

## Ko‘rinadigan qoldirilgan ota-band
- Sahifalar (Alumni / Loyihalar / Grantlar / Tadbirlar guruhi)

## Qayta ko‘rsatish
`public/tdyu-menu-mark.css` ichida quyidagini izohga oling yoki o‘chiring:

```css
.tdyu-ia-hide{display:none!important}
```
